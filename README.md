# FinancePulse – Personal Finance Management System

FinancePulse is a full-stack personal finance management application designed to help users manage their finances in one place. It provides a centralized dashboard to track accounts, income, expenses, transactions, bills, savings, and financial goals.

## 🌐 Live Demo

**Frontend:**  
https://madhusha221.github.io/FinancePlus/

> The frontend is currently hosted using GitHub Pages. Backend deployment is in progress.

## ✨ Features

- 🔐 User authentication
- 📊 Financial dashboard
- 💳 Account management
- 💰 Income tracking
- 💸 Expense tracking
- 🔄 Transaction management
- 🧾 Bill management
- 🎯 Savings and financial goals
- 📈 Spending analytics and trends
- 🔎 Search and date-based financial views
- 📅 Automatic date display
